# Native Canva diagrams

[Open the Canva master for viewing](https://www.canva.com/d/IDTTD9Ce011n5H1).

The 15 diagrams were created as native editable Canva designs from authored layout sources, with subsequent native edits. They are not generated bitmap illustrations relabelled as Canva output. `native_renders/` contains the actual page preview bytes returned by Canva; each diagram includes its manuscript figure number, title and arrow legend.

The Canva canvas is 1600 × 900 pixels, but the included exports are **596 × 335 pixel previews**. Obtain high-resolution images from the original Canva design before journal submission. Enlarging these preview files does not add detail. Access to edit or export depends on the owner's Canva permissions; this repository does not grant access to the account.

`native_diagram_text.txt` preserves text verified from the final native design. `subsystem_diagrams.html` and `diagram_specs.json` are the local authoring references used in preparing the design. They are not Canva exports and may precede final native wording adjustments. Use the Canva master, native text and actual rendered pages as the final diagram record.

`provenance.json` contains the stable view URL, design identifier, dimensions and image hashes. Internal connector responses, signed thumbnail links and draft design history are omitted from the public repository.
