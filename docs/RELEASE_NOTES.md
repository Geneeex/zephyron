# Initial Zephyron supporting-material release

Prepared 23 September 2026 for [arXiv:2609.25709](https://arxiv.org/abs/2609.25709).

This release provides the selected engineering baseline, scenario registries, analytical code and 16 CSV datasets; nine analytical figures in PNG and SVG; 12 engineering regression checks and 33 machine-learning data-handling and metric checks; the two executable manuscript listings; nine editable Blender scenes and renders; 15 genuine Canva preview renders with provenance; three original prototype photographs; the literature-scoping record and credited reused figures; and editable Word and LaTeX manuscripts.

The calculation verifier reproduces committed CSV bytes in the recorded Windows/Python environment. The supplied GitHub Actions workflow repeats verification and figure generation after upload. The recorded local report describes the environment and limits; hosted CI has not run during preparation.

This is a design-and-analysis supplement. It contains no new acquired physical rover measurements, trained model weights, experimental detection scores or demonstrated endurance ratings. Native Canva figures remain preview resolution. The locally editable manuscripts are not asserted to be byte-identical to the arXiv source deposit.
